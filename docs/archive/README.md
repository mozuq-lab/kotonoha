# アーカイブ — 歴史記録

このディレクトリの文書は**更新しません**。作成時点の記録として保存してあり、現在の実装とは食い違います。

## なぜ隔離したか

このプロジェクトは開発ワークフローに [Tsumiki](https://github.com/classmethod/tsumiki) を使っていたが、2026-08-28 に Tsumiki 前提の開発をやめた。ここにあるのは Tsumiki が生成したプロセス成果物で、実装が進んだ現在は再現しない。

隔離せずに残すと実害が出る。実際に次のことが起きていた。

- コードレビューの指摘が「規約違反」なのか「文書が古いだけ」なのか判別できず、議論が反証不能になった
- 存在しないディレクトリ（`services/`、`core/database.py`、`tests/test_services/`）を前提にした指摘が繰り返し出た
- 廃止済みの設定やライブラリのバージョンを、現行の仕様として読む余地が残っていた

## 何が入っているか

| | 内容 |
|---|---|
| `implements/` | タスク単位の TDD 実行記録（要件・テストケース・実装レポート・検証レポート）。299 ファイル |

いずれも「そのとき何を考えて何をしたか」の記録としては価値がある。**現在の仕様として読まないこと。**

## 現行の文書はどこか

| 知りたいこと | 参照先 |
|---|---|
| 要件 | `docs/spec/kotonoha-requirements.md` |
| 設計 | 決定は `docs/adr/`（索引は `AGENTS.md`） |

コードの実態と文書が食い違っていたら、**コードが正**である。文書側を直すか、直せないならここへ移すこと。
